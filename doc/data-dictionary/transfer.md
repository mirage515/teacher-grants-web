# transfer.csv 資料字典

## 檔案說明

此資料集記錄技術移轉或授權相關資訊，涵蓋技轉名稱、廠商、金額與合約期間，主要供技術成果轉化與產學合作分析使用。

## 欄位定義

| 欄位名稱 | 型別 | 說明 |
| --- | --- | --- |
| 識別號 | string | 技轉資料唯一識別碼。 |
| 年度 | string | 技轉或授權年度。 |
| 承接代表 | string | 代表承接人或主持人。 |
| 系所代碼 | string | 教師所屬系所代碼。 |
| 主聘系所 | string | 教師主聘系所。 |
| 教師姓名 | string | 技轉相關教師姓名。 |
| 專兼任 | string | 教師職務屬性。 |
| 技術移轉或授權 | string | 技術移轉或授權類型說明。 |
| 技轉/授權名稱 | string | 技轉或授權名稱。 |
| 技轉或授權廠商名稱 | string | 合作廠商名稱。 |
| 技轉或授權金額 | number | 技轉或授權金額。 |
| 技轉或授權起始日 | string | 技轉或授權起始日期。 |
| 技轉或授權終止日 | string | 技轉或授權終止日期。 |
| 合約編號 | string | 技轉或授權合約編號。 |
| 是否取得專利 | string | 是否同時取得專利。 |
| 專利證書字號 | string | 專利證書字號。 |

## 使用方式

- 可統計技術移轉與授權金額。
- 可比較不同年度、系所與教授的產學合作成效。
- 常用於 `/teachers` 頁面。
