# teaching_awards_114_115.csv 資料字典

## 檔案說明

此資料集記錄教學獎勵申請與核定資訊，涵蓋年度、申請型態、獎勵事項及金額，主要供教學成效與獎勵分析使用。

## 欄位定義

| 欄位名稱 | 型別 | 說明 |
| --- | --- | --- |
| 年度 | string | 教學獎勵年度。 |
| 申請編號 | string | 申請案件編號。 |
| 申請型態 | string | 申請類型或申請模式。 |
| 獎勵事項_1 | string | 第一項獎勵內容。 |
| 獎勵事項_2 | string | 第二項獎勵內容。 |
| 獎勵事項_3 | string | 第三項獎勵內容。 |
| 具體成效說明 | string | 申請的具體成效與成果描述。 |
| 系所 | string | 申請人所屬系所。 |
| 姓名 | string | 申請人姓名。 |
| 百分比 | number | 可用於計算或比例評估之百分比。 |
| 點數 | number | 獎勵評分或點數。 |
| 金額 | number | 核定或申請金額。 |

## 使用方式

- 可統計教學獎勵申請與核定狀況。
- 可依系所、年度、項目與人員進行分析。
- 常用於 `/teaching` 頁面。
