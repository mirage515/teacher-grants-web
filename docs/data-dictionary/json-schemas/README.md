# JSON 結構定義版

此目錄提供各 CSV 檔的 JSON Schema 定義，方便用於資料驗證、型別檢查、前端資料轉換與 API 共用格式定義。

## 檔案清單

- [grants_112_114.schema.json](grants_112_114.schema.json)
- [papers_112_114.schema.json](papers_112_114.schema.json)
- [projects_112_114.schema.json](projects_112_114.schema.json)
- [teaching_awards_114_115.schema.json](teaching_awards_114_115.schema.json)
- [teachers_114_2.schema.json](teachers_114_2.schema.json)
- [patent.schema.json](patent.schema.json)
- [transfer.schema.json](transfer.schema.json)

## 使用說明

JSON Schema 以 CSV 欄位名稱為 key，欄位型別與中文註解維持一致，以便後續資料處理與驗證共用。
