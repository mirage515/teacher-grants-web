# patent.csv 資料字典

## 檔案說明

此資料集記錄教師專利與新品種相關資訊，包括申請、審核、通過與授權狀態，主要供教師技術成果與專利分析使用。

## 欄位定義

| 欄位名稱 | 型別 | 說明 |
| --- | --- | --- |
| 識別號 | string | 專利資料唯一識別碼。 |
| 年度 | string | 專利或技術資料年度。 |
| 承接代表 | string | 代表承接人或主持人。 |
| 系所代碼 | string | 教師所屬系所代碼。 |
| 主聘系所 | string | 教師主聘系所。 |
| 教師姓名 | string | 專利相關教師姓名。 |
| 專兼任 | string | 教師職務屬性。 |
| 狀態 | string | 專利或技術狀態。 |
| 所屬計畫案 | string | 專利所屬研究計畫案。 |
| 專利/新品種名稱 | string | 專利或新品種名稱。 |
| 國別 | string | 專利申請或核發國別。 |
| 專利類型 | string | 專利類型，例如發明、設計等。 |
| 技術報告代碼 | string | 技術報告代碼。 |
| 進度狀況 | string | 技術或專利進度狀態。 |
| 技術報告審核完成日期 | string | 技術報告審核完成日期。 |
| 作者順序 | string | 教師在專利作者名單中的順序。 |
| 申請人/權利人 | string | 專利申請人或權利人名稱。 |
| 申請人/權利人類型 | string | 申請人/權利人類型。 |
| 申請日期/公告日期 | string | 申請日期或公告日期。 |
| 終止日期 | string | 專利終止或結束日期。 |
| 發照機關 | string | 發照機關名稱。 |
| 證書字號 | string | 證書字號。 |

## 使用方式

- 可用於專利數量與類型分析。
- 可比較不同系所、年度與教師的技術成果表現。
- 常用於 `/teachers` 頁面。
