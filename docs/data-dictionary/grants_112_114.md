# grants_112_114.csv 資料字典

## 檔案說明

此資料集記錄教師或系所在 112 至 114 年度之獎補助與補助金額資訊，主要用於獎補助分析與趨勢檢視。

## 欄位定義

| 欄位名稱 | 型別 | 說明 |
| --- | --- | --- |
| 年度 | string | 獎補助或補助發放的年度。 |
| 系所 | string | 受補助教師所屬系所名稱。 |
| 項目 | string | 獎補助主項目類別。 |
| 次項目 | string | 獎補助次項目或細分類別。 |
| 教師姓名 | string | 受補助或獲獎教師姓名。 |
| 獎助金額 | number | 獎助金額，通常以新臺幣計算。 |

## 使用方式

- 可作為年度獎補助總額統計。
- 可依系所、項目、教師進行分群分析。
- 常用於 `/grants` 頁面展示。
