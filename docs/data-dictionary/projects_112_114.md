# projects_112_114.csv 資料字典

## 檔案說明

此資料集記錄計畫執行與經費資訊，涵蓋研究計畫類型、經費來源、執行期間與計畫主導教師資訊，主要用於計畫承接分析與研究產出統計。

## 使用方式

- 可統計各年度計畫執行量與經費規模。

- 常用於 `/projects` 與 `/teachers` 頁面。
