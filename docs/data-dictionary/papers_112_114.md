# papers_112_114.csv 資料字典

## 檔案說明

此資料集記錄論文發表內容與相關屬性，涵蓋作者排序、論文分類、發表年份與期刊相關資訊，主要供論文發表分析與教師研究表現統計使用。

## 欄位定義

| 欄位名稱 | 型別 | 說明 |
| --- | --- | --- |
| 主聘系所 | string | 教師主聘系所名稱。 |
| 作者順序 | string | 教師在論文作者名單中的順序。 |
| 刊物名稱 | string | 發表論文所屬期刊、會議或刊物名稱。 |
| 專兼任 | string | 教師的職務性質，例如專任或兼任。 |
| 年度 | string | 計畫年度或資料統計年度。 |
| 所屬計畫案 | string | 論文所屬計畫案名稱或編號。 |
| 教師姓名 | string | 論文作者或對應教師姓名。 |
| 是否具有審稿制度 | string | 是否為具審稿制度之刊物。 |
| 期刊出版地國家/地區 | string | 期刊出版所在國家或地區。 |
| 期刊論文是否為跨國(地區)合作 | string | 是否為跨國或跨地區合作論文。 |
| 狀態 | string | 論文目前狀態，例如已發表、受理等。 |
| 發表卷數 | string | 論文發表卷數資訊。 |
| 發表型式 | string | 論文發表形式，例如論文、會議論文等。 |
| 發表年份 | string | 論文發表年份。 |
| 發表月份 | string | 論文發表月份。 |
| 發表期數 | string | 期刊發表期數。 |
| 系所代碼 | string | 教師或研究單位代碼。 |
| 論文名稱 | string | 論文標題。 |
| 論文收錄分類 | string | 論文於資料庫或索引中的收錄分類。 |
| 識別號 | string | 論文識別號或唯一編號。 |
| 通訊作者 | string | 通訊作者姓名。 |

## 使用方式

- 可用於論文發表量統計。
- 可分類分析不同系所、年份、類型與地區。 
- 常用於 `/papers` 與 `/teachers` 頁面。
